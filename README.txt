# Tutum Atölyesi DISC Davranış Anketi

Bu paket yalnızca DISC bölümünü içerir. Değer Profili / Hartman ve Motivasyon bölümleri kaldırılmıştır.

Kullanım: index.html dosyasını tarayıcıda açın. Katılımcı bilgileri ve 24 DISC grubu tamamlandığında yanıt çıktısı alınabilir.

Soru ifadeleri DISC_skorlama_motoru_kodlanmis_sablona_gore.xlsx dosyasındaki MAP sayfasından alınmıştır. Web ekranında görünen ifadeler MAP sayfasındaki “Açıklanmış anlamı” sütunundaki metinlerdir; kart altındaki küçük satırda Word No ve “İfade” sütunu da korunmuştur.
